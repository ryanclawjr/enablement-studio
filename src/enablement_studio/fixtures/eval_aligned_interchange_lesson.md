# Interchange teach-back

Title: Explain interchange

## Learning objective
The learner will explain interchange using the authorization and settlement
path, as measured by a 90-second teach-back scored on a 3-point rubric.

## Activity
Paired practice: explain interchange using the authorization and settlement
path. The partner only scores the teach-back rubric.

## Assessment
In 90 seconds, explain interchange using the authorization and settlement
path. Score the same teach-back rubric: accuracy, sequence, one follow-up.
